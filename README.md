# TwinBee PARADISE in Donburi Island Research
A work in progress research project of the game TwinBee PARADISE in Donburi Shima for Windows 95. This research covers how game the operates in Macromedia/Adobe Director in terms of the code, logic, and the environments it can operate on. This research will cover Reverse Engineering, Software Archaeology, & Environment Dependencies with other topics such as identifying file formats and preservation. There will be flowcharts presented for the logic of the code/events and the structure of the game.

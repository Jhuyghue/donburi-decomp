# 2. About The Software
*TwinBee PARADISE in Donburi Shima* (ツインビーPARADISE in どんぶり島 Tsuinbī PARADISE in Donburi Shima) is an interactive multimedia game authored in **Macromedia/Adobe Director** developed and published by Konami. It was only released in Japan in 1998 for Windows 95[^1]. 
The player is hosted by Pastel and WinBee, who welcome them and guide them on a tourist trip around the island. After entering, the player sees an aerial view of the island and chooses landmarks to visit, each containing a different activity. The game doesn't have a clear goal, but it emphasizes on exploration, which can give players the freedom to explore the island, learn facts about the series and games released, take quizzes, watch videos, listen to stories, and interact with characters. 

## 2.1 Why it Matters For Preservation 
This game matters for preservation because the major reason is the situation around **Macromedia Director** itself. The great thing about Director is that it was a very easy software for developers to create video games for PC systems. Even if you didn't know programming, you still can make presentations, portfolios, or animations[^2]. It really defined the multimedia era of the 90's to late 2000's, but it did pave the way for point and click adventure games which was popularized by CD-ROM titles like *Myst*[^3]. 

The main problem is Director was mostly built on old versions of Windows and Macintosh based operating systems. To play Director games, you have use an desktop or laptop with an CD drive that has an older version of the OS that can support it. If you don't have access to a device that supports a older operating system, you have to emulate it via *ScummVM*, *DOSBox*, or using a virtual machine like *Virtual Box* to install the specific OS to run then play the game. You could go to GOG.com and buy a game made in Director but it comes wrapped in an emulator. 

There are other games that aren't re released or offered on a storefront because of licensing issues since they are complex to handle especially if the original company who made the game when defunct years ago[^4]. The other reason is that it is hard to replicate Director since Adobe stopped releasing it after 2013 and stopped giving updates around 2017[^5]. There's not a lot of tutorials you can easily find that shows you how the software works and the lack of details about Lingo coding on the version you're using and applying it. 

## 2.2 Technical Specifications/Issues
Here are the specifications from the manual:

| Items |Recommended Requirements |
| :--- | --- |
|OS |Microsoft Windows 95 (Japanese Edition)| 
|CPU |Pentium 100 MHz or higher (133 MHz recommended)|
|Memory |16 MB or more (32 MB or more recommended). With less memory, movies and audio may stutter.|
|Sound |Windows 95 compatible sound card|
|CD-ROM Drive|4x read speed (8x read speed or faster recommended)|
|Hard Disk|5 MB or more free space|
|Display|640×480 or higher, High Color (16-bit) or higher. Does not run correctly in 256 color mode.| 

There are extra notes from the manual that state that the **QuickTime** for Windows has to be installed to make the game work correctly and the software may not run correctly on some hardware configurations, even if the specifications are met with the recommend [^6]. 

The CD-ROM game fully depends on proprietary components that are required when it was released, but now it's considered obsolete. The issues with them are listed as follows: 
- The **QuickTime** version it uses is discontinued and external media players for video games aren't required most game engines can play standard video files than proprietary ones. 
- The environment only relies on Japanese encoding or Shift-JS. If you ran it in environment where it doesn't support Japanese, it will display broken text (mojibake) which can display the wrong text in gameplay or it never runs due to the error.
- It may have audio issues since it mostly relies on older sound cards.
